How this works

A GitHub Action scans each competitor's XML sitemap every day. It records pages that were added, removed or had their lastmod date change. For new and changed pages it also checks the title, meta description, H1, canonical and HTTP status.

To add competitors, edit scraper/clients.yaml. You can track up to 5 per client.
